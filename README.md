# 🚚 Logistics Data Analysis Using Python

## 📌 Overview

This project focuses on **Strategic Planning and Data Exploration in Logistics** using an e-commerce order dataset. The goal is to analyze logistics performance, delivery efficiency, shipping costs, customer distribution, and order trends using Python.

## 🎯 Objectives

* Clean and preprocess logistics data
* Perform Exploratory Data Analysis (EDA)
* Analyze delivery performance
* Calculate important logistics KPIs
* Analyze shipping costs and customer distribution
* Generate useful business insights

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## 📂 Dataset

The project uses five datasets:

* Customers
* Orders
* Order Items
* Payments
* Products

## 📊 Key KPIs

* Total Customers
* Total Orders
* Delivery Success Rate
* Average Delivery Time
* On-Time Delivery Rate
* Late Delivery Rate
* Average Shipping Cost
* Total Shipping Cost
